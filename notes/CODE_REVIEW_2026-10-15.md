## C. Robustness (silent failures)

- `except Exception: print(...); continue` hides failed regressions in `14_gshs_analysis.py:30`, `18_mics_analysis.py:41,60`, `22_gshs_itu.py:20` (tables can be silently incomplete), and failed PDF parses in `parse_il/me/pa/wa.py`; `mics_extract.py:16` drops a sample on any read error (the report hard-codes "68 surveys").
- `90_build_report.py:402` uses `eval()` on a CSV cell written by `23_state_surveys.py:39` (a Python list string). Use `ast.literal_eval` or write `;`-joined values.
- `18_mics_analysis.py:10,21,58`: SEXFS = 9 counted as boys; URBAN 5/NaN counted as rural; `INTFREQ3MO = 9` with `INTEVER = 1` coded 0; EDCURR_FS = 9 (10% of 15–17) silently dropped in the own-use models; unweighted means next to weighted regressions.
- `25_pisa_phone_bans.py:14`: the private-school control is all zeros (string column compared to 1) and is dropped as collinear, so the model's stated control is absent.
- `13_yrbs_state.py:7-9`, `12_validation.py:31`: `sex` is parsed as string only because "." markers are present; with chunked reads a chunk without "." would parse as int and be dropped. Set `dtype={"sex": str}`. `se = 0` when p ∈ {0,1} gives infinite weights.
- `11_ipumsi_census.py:40`: heteroskedastic SEs with a district-level regressor; cluster by district. SEX = 9 rows kept.
- `22_gshs_itu.py:7-8`: 4G coverage set to 0 before 2012 for every country, including those with no ITU series.
- `10_event_study.py:22`: undated markets treated as never-treated in the `_with_untreated` spec (documented as a bound in the report; the docstring should say so and the dated-only spec should be primary).
- `93_docx_fix.py`: bare `except Exception: pass`; zip handles not in `with`.
- `wdi_fetch.py`, `gshs/01_download_gshs.py`, `state_surveys/*_download.py`: no `raise_for_status`, personal e-mail in a User-Agent, failed downloads only printed.
- `build_lte_launches.py`: a further 11 manual codes point at the wrong state and are silently replaced by auto-matching; duplicate dict key "Green Bay, WI".
- `build_state_policy_timing.py:424`: Race to the Top flagged from the school year ending in the award year, inconsistent with the month rule used for waivers.
